# Шахматы с ИИ на Python

Проект представляет собой шахматную игру с графическим интерфейсом, разработанную на языке Python с использованием библиотеки Tkinter.

## Возможности

### Игровой процесс

* Полноценная шахматная доска 8×8.
* Корректная начальная расстановка фигур.
* Поддержка всех основных фигур:

  * Пешка
  * Ладья
  * Конь
  * Слон
  * Ферзь
  * Король
* Проверка допустимости ходов.
* Запрет взятия своих фигур.
* Проверка свободного пути для ладьи, слона и ферзя.
* Смена хода между белыми и чёрными.
* Возможность выбора стороны перед началом партии.
* Автоматический переворот доски при игре за чёрных.
* Реализована рокировка.

### Искусственный интеллект

* Игра против компьютера.
* Автоматический ход ИИ после хода игрока.
* Генерация всех допустимых ходов.
* Выбор случайного допустимого хода.

### Интерфейс

* Графический интерфейс на Tkinter.
* Отрисовка шахматных фигур через Unicode-символы.
* Подсветка выбранной фигуры.
* Простое и удобное управление мышью.

## Используемые технологии

* Python 3
* Tkinter
* Random
